How it works

Three steps from applicant details to a result you can read at a glance.

Enter the details

Fill in the six required fields and, ideally, the external credit scores. The other fields can be left blank.

The model estimates the risk

A Gradient Boosting model trained on historical loan data returns an estimated default probability.

Review the result

See the estimate next to the 10% review threshold, with a reliability level and any warnings.

What you can do here

The project combines a prediction tool with the analysis behind it.

Risk estimate

See the estimated probability next to the 10% review threshold and the 8.07% historical default rate.

Reliability awareness

When external scores are missing, the estimate carries a reliability level and a warning based on measured test results. With no scores, no risk label is shown.

Power BI dashboard

Explore default rates by credit score, age, occupation and income in the dashboard built from the MySQL data.

Session analytics

Review the predictions made during your current session, kept separate from the historical data.

A decision-support tool. The estimate reflects how similar historical applicants behaved. It is not a loan decision, and it does not mean any applicant will default. Read the About page for the limitations.

Go to Risk Prediction

Decision-support tool only. The model was trained on historical data and shows associations, not causes. It uses information that this site does not collect, including gender, which is filled with a typical value. Fields left blank are also filled with typical values. Do not use it as the only basis for a credit decision.
